# Trademark and project identity policy

The names **"Aegis"** and **"Aegis Ecosystem"**, the logo and the visual
identity of the project are **not** licensed under AGPL-3.0.

## Allowed

- Refer to the unmodified project by its name.
- State that your product integrates with Aegis, if that is true.
- Redistribute the unmodified code with the original copyright, NOTICE and
  SPDX notices.

## Not allowed

- Use the name or logo for a modified fork in a way that suggests endorsement
  by the project.
- Register domains, package names, social accounts or company names that are
  confusingly similar.
- Remove copyright, NOTICE or SPDX notices from the source.

Forks must use a different name and logo. This is a project policy; it is not
a claim that the name is a registered trademark. The preliminary name search
and the limits of this policy are documented in
[`docs/archive/TRADEMARK_RESEARCH.md`](docs/archive/TRADEMARK_RESEARCH.md). For permission, open
an issue in the repository.
